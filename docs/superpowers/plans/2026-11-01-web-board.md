# Web Board Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an opt-in web board, running inside the bot process, to view, edit and delete scheduled posts with the live scheduler kept in sync.

**Architecture:** A new `bot/web/` package. Pure units (`captions`, `auth`, `timeutil`, `media`, `rules`, `queries`, `service`) hold all rules and are tested without HTTP. `server.py` and `api.py` are a thin aiohttp layer started from `main.py` `post_init` on the bot's event loop, receiving the live `PostScheduler`. The UI is static vanilla JS served by the same app.

**Tech Stack:** Python >=3.11, aiohttp 3.x, python-telegram-bot 20.8, APScheduler 3.11, SQLite, Pillow, pytz, pytest; vanilla JS/CSS; Playwright (manual smoke only).

**Spec:** `docs/superpowers/specs/2026-11-01-web-board-design.md`

## Global Constraints

- Python `>=3.11`. Dependencies: `aiohttp>=3.10,<4` in `pyproject.toml`, `Dockerfile` and CI; `aiohttp==3.14.5` in `requirements.txt`. Pillow is already a dependency.
- `bot/web/__init__.py` stays empty. Only `server.py` and `api.py` import aiohttp, so every other module imports without it.
- All times are Kyiv (`Europe/Kiev`, pytz). Stored via `serialize_dt` / `parse_dt` / `kyiv_now_iso` from `bot/database.py`. Compare parsed datetimes, never strings. SQL time ordering uses `CAST(strftime('%s', col) AS INTEGER)`.
- Database access: `Database.get_connection()` (new connection per call). Blocking DB, filesystem and Pillow work in the web layer runs via `asyncio.to_thread`. Scheduler calls run on the loop.
- Schema changes are additive (`CREATE TABLE IF NOT EXISTS`, `ALTER TABLE ... ADD COLUMN` in try/except) inside `init_database`.
- The board is off unless `WEB_BASE_URL` is set. It refuses to start if `ALLOWED_USER_IDS` is empty, if the URL is not `https://` (except `http://localhost` / `http://127.0.0.1`), or if the URL has a path.
- Login token: `secrets.token_urlsafe(32)`, stored as sha256 hex, TTL 300 s, single use, consumed by `POST /login` only. Session id: `secrets.token_urlsafe(32)`, stored as sha256 hex, TTL 7 days, cookie `tgs_session` (`HttpOnly`, `SameSite=Lax`, `Path=/`, `Secure` iff the base URL is https). Failed logins: 20 per 300 s globally, then `429`.
- Every non-GET request needs `Origin` equal to the origin of `WEB_BASE_URL`; non-GET `/api` requests also need header `X-Board: 1`. A user no longer in `ALLOWED_USER_IDS` gets `403` on every request.
- Response headers on every response: `Content-Security-Policy: default-src 'self'; img-src 'self' data:; media-src 'self'; script-src 'self'; style-src 'self'; base-uri 'none'; form-action 'self'; frame-ancestors 'none'`, `X-Content-Type-Options: nosniff`, `Referrer-Policy: no-referrer`; `Cache-Control: no-store` on `/api` unless a route sets its own. The aiohttp access log is disabled (`access_log=None`).
- Errors are JSON `{"error": code, "message": text}`: `invalid_request` 400, `unauthorized` 401, `forbidden` 403, `not_found` 404, `conflict` 409, `too_large` 413, `rate_limited` 429, `internal` 500. A post that is not yours and a post that does not exist are both `404`.
- Caption limit 1024 characters (`len(text)`). Minimum lead for a scheduled time: 60 s. Post-now time: now + 60 s. Retry without a future time: now + 10 s.
- Upload cap 50 MB (`413`). `PHOTO_MAX_BYTES = 10 * 1024 * 1024`: a larger photo is stored as `document`. Thumbnails: WebP in `config.THUMBS_DIR`, purged after 14 days. Bulk: at most 500 ids. List `limit`: default 50, max 100.
- Rows-then-files: commit the database change before deleting any file; on failure remove the new file and leave the old state untouched.
- Front end: vanilla JS and one CSS file, no build step. Write API strings with `textContent` / `setAttribute`, never `innerHTML`; the only exception is server-sanitized `caption_html` into `#caption-preview`. Times shown in the UI are sliced from the server's Kyiv ISO strings; the browser's time zone is never used.
- Tests: pytest with `tests/conftest.py` (fresh database per test). Async code is tested through `asyncio.run`; no new pytest plugins.

## Review Focus

Inputs and conditions the spec implies that a person is likely to hit. Each has a named test in the owning task.

1. A caption containing a raw `<` or `&` ("I <3 you & AT&T, 5 < 10") must be saved exactly as typed, not rejected as a bad tag. (Task 2)
2. Several posts at the identical scheduled time (the bot puts all channels on the same slots) straddling a page boundary must each appear exactly once. (Task 6)
3. A post whose media file is gone from disk (published media is deleted after 7 days) must still list and open, with a placeholder instead of a broken image, and replacing its media must still work. (Tasks 5, 9, 11)
4. Searching Ukrainian text in a different letter case ("привіт" must find "Привіт") and searching for `%` or `_` literally. (Task 6)
5. A browser that is not in Kyiv time zone must still show and submit Kyiv wall-clock times, with "Kyiv time" labelled. (Task 14)

### Task 6: Status rules and read queries

**Files:**
- Create: `bot/web/rules.py`, `bot/web/queries.py`, `tests/web_helpers.py`, `tests/test_web_queries.py`
